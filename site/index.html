PC なしで、Frame の中だけで手短にインストールNo PC needed — install right inside the Frame, in a few minutes.

Frame の Konsole にこのコマンドを入力して Enter。あとはメニューから、ほしいアプリの番号を選ぶだけ。1 つだけでも、5 つ全部でもインストールできます。 Type this command into Konsole on your Frame and press Enter. Then pick the apps you want from the menu: just one, or all five. 

curl -fsSL https://frame.sasaken1102s.net | sh

PC から SSH で入れる人向けFor installing over SSH from a PC

このコマンドで実行されるコードは、GitHub の sasaken1102r/frame で公開しています。中身を確かめてから使えます。The code this command runs is published on GitHub at sasaken1102r/frame, so you can check it before using it.

コマンドの読み方How to read the command

左から順に入力します。 のところには半角スペースを 1 つ（全部で 4 か所）。文字はすべて半角です。Type it from left to right. Put one space at each (4 in all).

  1. curl カール。小文字の c・u・r・l。インストール用のスクリプトをダウンロードするLowercase c, u, r, l. Downloads the install script
  2. スペースspace
  3. -fsSL マイナス（ハイフン）のあとに、エフ・エス・エス・エル。うしろの S と L は大文字A hyphen (minus), then f, s, S, L. The last S and L are capitals
  4. スペースspace
  5. https://frame.sasaken1102s.net このページのアドレス。https のあとに ://、sasaken のあとは数字の 1102。全部小文字The address of this page. :// after https, the number 1102 after sasaken, all lowercase
  6. スペースspace
  7. | 縦棒。SteamVR の純正キーボードでは、Backspace の下のキーVertical bar. On the stock SteamVR keyboard, it's the key below Backspace
  8. スペースspace
  9. sh エス・エイチ（小文字）。ダウンロードしたスクリプトを動かす。最後に EnterLowercase s, h. Runs the downloaded script. Then press Enter
  • sudo・パスワードは要らないNo sudo, no password
  • ホームフォルダの中にだけインストールOnly writes inside your home folder
  • 同じコマンドで更新・アンインストールSame command to update or uninstall

使い方How to use

ヘッドセットの中で、上から順に進めれば大丈夫です。Do these on the headset, from top to bottom.

  1. 1

    開発者モードをオンにする（最初の 1 回だけ）Turn on Developer Mode (only the first time)

    画面の下のバーの Steam ボタン →［Steam設定］→ 左の［システム］を開いて、「開発者モードを有効化」をオンにします。これで Konsole が使えるようになります。Press the Steam button on the bar at the bottom → Settings → System on the left, and turn on Enable Developer Mode. This makes Konsole available.

    一度オンにすれば、次からはこの手順は要りません。Once it is on, you can skip this step from then on.

  2. 2

    Konsole を開くOpen Konsole

    画面の下のバーにある ＋ を押すと「プログラムを起動」の一覧が出ます。その中の Konsole を選びます。デスクトップモードに切り替える必要はありません。Press + on the bar at the bottom of your view to open the list of programs, then pick Konsole. No need to switch to Desktop Mode.

    Konsole は、文字を打ってコンピューターに指示を出すアプリ（ターミナル）です。Konsole is a terminal: an app where you type commands.

  3. 3

    コマンドを入力して EnterType the command and press Enter

    Konsole に、このコマンドを入力して Enter を押します。区切りごとの打ち方は、上の「コマンドの読み方」にあります。Type this command into Konsole and press Enter. See “How to read the command” above for each part.

    curl -fsSL https://frame.sasaken1102s.net | sh

    2 回目からは ↑ キー。Konsole で ↑ を押すと、前に入力したコマンドが出てきます。更新するときは ↑ → Enter だけで大丈夫です（あとで別のコマンドを打っていたら、↑ を何回か押す）。Next time, use the ↑ key. Pressing ↑ in Konsole brings back the command you typed before. To update, just press ↑ → Enter (if you typed other commands since, press ↑ a few times).

困ったときTroubleshooting

「プログラムを起動」の一覧に Konsole がない
開発者モードがオフになっています。手順 1 のとおり、Steam ボタン →［Steam設定］→［システム］の「開発者モードを有効化」をオンにしてください。
command not found（コマンドが見つかりません）などが出る・何も起きない
入力したコマンドが少し違っているかもしれません。↑ で呼び出して、次を確かめて直してから Enter。
  • スペース：curl・-fsSL・アドレス・|・sh の間に 1 つずつ（4 か所）
  • 大文字と小文字：大文字は -fsSL の S と L だけ
  • 最後の | sh：抜けていると、文字（スクリプトの中身）がたくさん出て終わります
  • curl: (6) Could not resolve host のように curl: で始まる表示は、curl（ダウンロード）のエラーです。アドレスの綴りと、ヘッドセットがネットにつながっているかを確かめてください
コピーできない・貼り付けられない
SteamVR の純正キーボードでは、コピー＆ペーストができません。上の「コマンドの読み方」を見ながら入力してください（PC から SSH でつないでいるなら［コピー］が使えます）。
結果に「失敗」と出た
横に理由が出ています。直したら、もう一度同じコマンドを実行してください（↑ → Enter）。
  • 「GitHub につながりません」…ヘッドセットがネットにつながっているか確かめる
  • 「ダウンロードできません」「SHA-256 が合わない」…ダウンロードが途中で壊れたかも。そのままもう一度
  • 「install.sh が失敗（上の出力を見てね）」…その上に出ている表示に理由があります
「1〜5 の番号か、a / u / q を入力してね」と出る
番号は半角で打ってください（全角の「１」は通りません）。いくつか選ぶときはスペースで区切ります。
「root では動かしません」「これは Steam Frame（aarch64）用です」と出て止まった
コマンドの前に sudo を付けずに、PC ではなくヘッドセットの Konsole で実行してください。
「（y: はい / n: いいえ。…）」で止まっている
質問の答えを待っています。y か n を打って Enter。Enter だけなら、かっこの中の「Enter だけなら」の答えで進みます。
Konsole is not in the list of programs
Developer Mode is off. As in step 1, press the Steam button → Settings → System and turn on “Enable Developer Mode”.
It says command not found or something similar, or nothing happens
The command you typed is probably a little off. Bring it back with ↑, check these, fix it and press Enter.
  • Spaces: one between curl, -fsSL, the address, | and sh (4 in all)
  • Capitals: only the S and L in -fsSL
  • | sh at the end: without it, lots of text (the script itself) is printed and it ends
  • Messages starting with curl:, like curl: (6) Could not resolve host, come from curl (the download). Check the spelling of the address and that the headset is online
I can't copy and paste
The stock SteamVR keyboard can't copy and paste. Type the command, following “How to read the command” above. (If you are connected from a PC over SSH, the Copy button works.)
The result says “FAILED”
The reason is shown next to it. After fixing it, run the same command again (↑ → Enter).
  • “cannot reach GitHub” … check that the headset is online
  • “download failed” or “SHA-256 mismatch” … the download probably broke; just try again
  • “install.sh failed (see its output above)” … the lines above it tell you why
It says “Type numbers 1-5, or a / u / q”
Type the menu numbers; separate several with spaces.
It stopped with “Don't run this as root” or “This is for the Steam Frame (aarch64)”
Run the command without sudo, in Konsole on the headset (not on your PC).
It is waiting at “(y = yes / n = no, …)”
It is waiting for your answer. Type y or n and press Enter. Just Enter gives the answer shown after “Enter =”.

詳しい人向け（質問なしで使う・オプション・中でやること）For advanced users (no questions, options, what it does)

質問なしで使うWithout questions

ヘッドセットでは入力、PC から SSH でつないでいるなら［コピー］が使えます。Type these on the headset; over SSH from a PC, the Copy buttons work.

curl -fsSL https://frame.sasaken1102s.net | sh -s -- install eye mic
curl -fsSL https://frame.sasaken1102s.net | sh -s -- install all --yes
curl -fsSL https://frame.sasaken1102s.net | sh -s -- uninstall perf

オプションOptions

  • アプリ名は短く eye keyboard mic perf でも、all で全部
  • --yes 質問にはすべて既定の答えで進む（ターミナルが無いときも同じ）
  • --lang ja|en 表示の言語（既定はロケール、無ければ Steam の言語設定）
  • --help 使い方
  • App names can be short: eye keyboard mic perf, or all
  • --yes takes the default answer for every question (also when there is no terminal)
  • --lang ja|en language of the messages (default: the locale, else Steam's language setting)
  • --help usage

インストール済みの版のほうが最新リリースより新しいときは、聞いてから戻します（--yes のときは戻さずにそのまま）。If the installed version is newer than the latest release, it asks before going back (with --yes it keeps the installed one).

やること・やらないことWhat it does and doesn't do

  • 各アプリの GitHub の最新リリースから tar.gz と SHA256SUMS をダウンロードし、SHA-256 が合ったものだけをインストールします。アーカイブに絶対パスや ..、リンクが入っていたら止めます
  • 展開したリリースの install.sh を実行するだけです。手で ./install.sh したときと同じで、出力もそのまま見えます
  • sudo は使いません。書き込むのはホームフォルダの中だけです（一時フォルダ ~/.cache/frame-installer/ は終わったら消します）
  • SHA256SUMS は同じリリースに付いているチェックサムで、ダウンロードの破損は防げますが、署名ではありません
  • It downloads each app's latest GitHub release (tar.gz) with its SHA256SUMS and installs only when the SHA-256 matches. It refuses archives with absolute paths, .. or links
  • It just runs the release's own install.sh, the same as running ./install.sh by hand, with its output visible
  • No sudo. It writes only inside your home folder (the temporary folder ~/.cache/frame-installer/ is removed at the end)
  • SHA256SUMS comes with the same release: it catches broken downloads, but it is not a signature
