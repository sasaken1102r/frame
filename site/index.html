使い方How to use

ヘッドセットの中で、上から順に進めれば大丈夫です。Do these on the headset, from top to bottom.

  1. 1

    下のボタン（上のものと同じ）を押します。緑になって「コピーした」と出れば OK です。Press the button below (same as the one at the top). It turns green and says “Copied” when it worked.

    curl -fsSL https://frame.sasaken1102s.net | sh
  2. 2

    Konsole を開くOpen Konsole

    デスクトップモードに切り替えて、アプリの一覧から Konsole を開きます。Switch to Desktop Mode and open Konsole from the app list.

    Konsole は、文字を打ってコンピューターに指示を出すアプリ（ターミナル）です。Konsole is a terminal: an app where you type commands.

  3. 3

    コマンドを貼り付けて EnterPaste the command and press Enter

    Konsole の中で 右クリック →［貼り付け］、またはキーボードで Ctrl + Shift + V。貼り付けたら Enter を押します。In Konsole, right-click → Paste, or press Ctrl + Shift + V. Then press Enter.

    Ctrl + V では貼り付けられません。Konsole では Shift も一緒に押します。Ctrl + V does not paste in Konsole. Add Shift.

詳しい人向け（質問なしで使う・オプション・中でやること）For advanced users (no questions, options, what it does)

質問なしで使うWithout questions

curl -fsSL https://frame.sasaken1102s.net | sh -s -- install eye mic
curl -fsSL https://frame.sasaken1102s.net | sh -s -- install all --yes
curl -fsSL https://frame.sasaken1102s.net | sh -s -- uninstall perf

オプションOptions

  • アプリ名は短く eye keyboard mic perf でも、all で全部
  • --yes 質問にはすべて既定の答えで進む（ターミナルが無いときも同じ）
  • --lang ja|en 表示の言語（既定はロケール、無ければ Steam の言語設定）
  • --help 使い方
  • App names can be short: eye keyboard mic perf, or all
  • --yes takes the default answer for every question (also when there is no terminal)
  • --lang ja|en language of the messages (default: the locale, else Steam's language setting)
  • --help usage

インストール済みの版のほうが最新リリースより新しいときは、聞いてから戻します（--yes のときは戻さずにそのまま）。If the installed version is newer than the latest release, it asks before going back (with --yes it keeps the installed one).

やること・やらないことWhat it does and doesn't do

  • 各アプリの GitHub の最新リリースから tar.gz と SHA256SUMS をダウンロードし、SHA-256 が合ったものだけをインストールします。アーカイブに絶対パスや ..、リンクが入っていたら止めます
  • 展開したリリースの install.sh を実行するだけです。手で ./install.sh したときと同じで、出力もそのまま見えます
  • sudo は使いません。書き込むのはホームフォルダの中だけです（一時フォルダ ~/.cache/frame-installer/ は終わったら消します）
  • SHA256SUMS は同じリリースに付いているチェックサムで、ダウンロードの破損は防げますが、署名ではありません
  • It downloads each app's latest GitHub release (tar.gz) with its SHA256SUMS and installs only when the SHA-256 matches. It refuses archives with absolute paths, .. or links
  • It just runs the release's own install.sh, the same as running ./install.sh by hand, with its output visible
  • No sudo. It writes only inside your home folder (the temporary folder ~/.cache/frame-installer/ is removed at the end)
  • SHA256SUMS comes with the same release: it catches broken downloads, but it is not a signature
